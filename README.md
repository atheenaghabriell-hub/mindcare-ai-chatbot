# MindCare AI Chatbot

## Overview

A web-based AI Mental Health Support Chatbot developed for capstone research.

## Objectives

- Provide preliminary emotional support
- Detect user sentiment
- Recommend mental health resources
- Maintain conversation history

## Tech Stack

- Laravel
- Bootstrap
- PostgreSQL
- Gemini API
- VADER Sentiment Analysis

## Status

Planning Phase

## Administrator log reader

Signed-in administrators can open **Application logs** from the navigation to read recent `.log` files in the app's `storage/logs` folder. The reader shows at most the latest 300 lines and reads no more than 512 KB per request. Hosting-provider logs and logs stored outside this folder are not available in the app.
